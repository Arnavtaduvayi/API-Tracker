Tethra

A local-first desktop app and CLI for developers to organize, secure, and track the API credentials scattered across their projects.

How to open it the first time
  1. Open the DMG and drag Tethra.app to Applications.
  2. Right-click Tethra.app → Open → Open (needed once),
    or run xattr -dr com.apple.quarantine "Tethra.app".
  3. Optionally verify the download first: shasum -a 256 Tethra.dmg

Everything stays on your computer

There is no account, no cloud service, no telemetry, and no Tethra server. The only network traffic Tethra ever produces is direct traffic between your machine and the API providers you explicitly configure — your secrets are never uploaded anywhere.

What it does

Encrypted vault

Credentials encrypted at rest with Argon2id + XChaCha20-Poly1305. Master password never stored; revealing a secret always requires reauthentication.

Projects, like folders

Organize keys by project and environment. See at a glance what's expired, expiring, unused, stale, or reused across projects — with the evidence for every claim.

Secret scanning

Scan repositories and git history for committed secrets locally, and block bad commits with a managed pre-commit hook.

Usage & cost tracking

Sync usage from providers that support it, estimate costs against versioned local pricing, and set budget alerts. Nothing is ever invented — attribution limits are labeled honestly.

Secure injection

tethra run injects chosen credentials into a child process's environment — no .env file ever written, and Tethra's own secrets are scrubbed from the child.

Desktop + CLI, one vault

The app and the tethra CLI share the same encrypted vault and core logic. Rotation, backups, destinations, and alerts work from either.

The CLI in ten seconds

tethra init                              # create the encrypted vault
eval "$(tethra unlock --print-export)"   # start a session
tethra project create my-app --env production
tethra key add --project my-app --name openai --provider openai
tethra key reveal my-app/openai          # reauthentication required

The CLI ships in the source repository — build with cargo build --release -p api-tracker-cli.
